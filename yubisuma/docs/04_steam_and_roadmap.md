# 04. Steam リリース計画とロードマップ

## 1. Steam で必要な手続き

| 項目 | 内容 |
| --- | --- |
| Steamworks 登録 | Steam Direct 手数料 **100 USD / タイトル**（一定売上で返金）。税務・銀行情報の登録 |
| ストアページ | カプセル画像各種、スクショ 5 枚以上、トレーラー推奨。**公開前に審査あり** |
| 「近日登場」期間 | ストアページ公開からリリースまで **最低 2 週間**。ウィッシュリストを集める期間 |
| ビルド審査 | リリース前にビルドの審査（数営業日） |
| レーティング | Steam の質問票に回答（暴力表現などなし → 全年齢の想定） |
| オンライン必須表記 | 「インターネット接続が必要」をストアに明記。CPU 戦（オフライン練習）があると印象が良い |

※ 手数料・期間は変わることがあるので、着手時に Steamworks の最新ドキュメントで確認すること。

## 2. 販売形態の検討

| 案 | 長所 | 短所 |
| --- | --- | --- |
| **買い切り 300〜500円（推奨）** | サブ垢・荒らし抑止、課金設計が不要 | 購入障壁で人口が増えにくい |
| 基本無料＋見た目課金 | 人口が集まりやすい | サブ垢・チート増、運営負荷と課金設計が必要 |

推奨：**買い切り＋フレンドパス（購入者 1 人がいればプライベートマッチに未購入フレンドを招待可能）** を検討。
Steam の仕組み上フレンドパスは制約があるため、実現できない場合は「発売週セール」「2 本セット（ギフト）」で代替。

## 3. 人口対策（最重要リスク）

- カジュアルは CPU 補充で **いつでも即遊べる**
- ランクは待ち時間 60 秒で範囲撤廃。ピーク時間帯（夜 20〜24 時）を画面に表示して集中させる
- 「対戦待ち中に CPU 練習」ができる
- 配信・動画映え：公開演出の派手さ、配信者向けに「視聴者参加用ルームコード大表示モード」
- Steam Playtest（無料の事前テスト枠）で事前にコミュニティ（Discord）を作る
- 日本語圏中心で開始 → UI は最初から多言語対応の仕組みで作り、英語・中国語（繁/簡）を順次追加
  （英語名は "Thumbs Up!" 系のゲーム名で海外の同種遊び "Thumb game / Chopsticks" との差別化が必要）

## 4. ロードマップ

| マイルストーン | 期間目安 | 内容 | 完了条件 |
| --- | --- | --- | --- |
| **M0 ルール検証** | 1〜2 週 | サーバのルールエンジン（純粋関数）＋テスト、ブラウザの簡易プロトタイプで身内対戦 | 3 秒ウィンドウ・サドンデスの面白さを体感で確認 |
| **M1 オンライン 1v1** | 3〜4 週 | Godot クライアント、WebSocket、ルーム状態機械、プライベートマッチ（コード参加） | 別 PC 同士で安定して BO3 が遊べる |
| **M2 カジュアル 4 人** | 2〜3 週 | 多人数ルール、CPU Lv1〜3、カジュアルキュー、再接続 | CPU 補充込みで 4 人戦が回る |
| **M3 ランク** | 3 週 | Steam 認証、DB、Glicko-2、ランク表示、シーズン、ペナルティ | 100 体の Bot で自動対戦させレート分布が妥当 |
| **M4 Steam 統合** | 2 週 | 招待、Rich Presence、実績、Steam Deck 確認、ストアページ作成 | ストアページ審査通過 |
| **M5 Playtest** | 4 週 | Steam Playtest 公開、バランス調整（入力時間、迷いインジケータ等）、負荷試験 | 重大バグなし、D1 継続率の把握 |
| **M6 リリース** | — | 近日登場 2 週間 → 発売 | |

合計 **約 4〜5 か月**（1 人開発・兼業を想定するとこれの 1.5〜2 倍）。

## 6. 次に決めたいこと（オーナーへの確認事項）

1. ~~エンジン~~ → **Godot に決定**
2. ~~販売形態~~ → **買い切りに決定**
3. **迷いインジケータ** など実験的ルールをどこまで入れるか → M0 のプロトタイプで試して決めるのが推奨
