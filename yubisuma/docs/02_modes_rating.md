# 02. モード・マッチメイキング・レート設計

## 1. ランクマッチ（1v1）

### 形式
- **BO3（2 ゲーム先取）**。1 ゲーム目のコーラー先手はランダム、以降は前ゲームの敗者が先手
- 標準ルール固定、入力時間 3.0 秒
- 想定試合時間：3〜5 分

### レート：Glicko-2
- 内部値：rating (初期 1500) / RD（信頼度）/ volatility
- 1v1 に向く。RD により「新規は大きく動き、安定した人は小さく動く」
- 更新は **BO3 の結果単位**（ゲーム単位だと運の揺れが大きすぎる）

### 表示ランク
内部レートをそのまま見せると上下が激しく感じるため、**ランク帯 + ポイント** 表示にする。

| ランク | 表示レート目安 |
| --- | --- |
| ブロンズ I〜III | 〜1300 |
| シルバー I〜III | 1300〜1500 |
| ゴールド I〜III | 1500〜1700 |
| プラチナ I〜III | 1700〜1900 |
| ダイヤ I〜III | 1900〜2100 |
| マスター | 2100〜（ポイント数値表示＋リーダーボード） |

- 表示レート = `rating - 2 × RD`（保守的推定値）。RD が下がるほど実力に近づき「上がっていく体験」になる
- **昇格/降格のバッファ**：ランク境界をまたいで落ちる場合、3 戦ぶんの猶予（降格保護）
- **配置戦**：最初の 5 試合はランク非表示

### シーズン
- 3 か月ごと。シーズン開始時に `rating = 1500 + (rating - 1500) × 0.5`、RD を 150 に戻す（ソフトリセット）
- シーズン報酬：最高到達ランクに応じたアイコン/手のスキン（見た目のみ）

### 放置・切断
- 切断：30 秒の再接続猶予。その間は「前ラウンドの状態維持＋コール無効」で自動進行
- 猶予を超えたら **その BO3 は敗北**、レート通常どおり減少
- 繰り返す場合：ランク参加の一時停止（5 分 → 30 分 → 24 時間）

## 2. カジュアルマッチ（2〜4人）

- キュー時に「人数：2〜4 / 4 人希望」を選択（初期は 4 人固定キューのみでも可）
- **CPU 補充**：20 秒待って 4 人揃わなければ CPU で埋める。CPU は名前で分かるよう表示（騙さない）
- 1 ゲーム勝負。終了後「同じメンバーでもう一度」投票
- 内部レート：**OpenSkill（Plackett-Luce）** で順位から更新。マッチングにのみ使用し非公開
  - OpenSkill は TrueSkill 相当で多人数・順位制に対応し、ライセンスが緩い（MIT）
- 抜けてもペナルティ軽め（CPU が引き継ぐ）

### CPU の強さ
- Lv1：完全ランダム
- Lv2：相手の直近履歴の頻度から期待値最大の数字をコール
- Lv3：Lv2 + 自分の出し方を相手の読みから外す（混合戦略）
- カジュアル補充は内部レートに応じて Lv を選択

## 3. プライベートマッチ

- ホストがルーム作成 → **6 桁のルームコード**（紛らわしい文字 0/O/1/I を除外）
- Steam フレンド招待（Steam のオーバーレイから「ゲームに参加」できるよう Rich Presence に connect 文字列を設定）
- 設定可能項目：人数 2〜4 / 入力時間 / 先取数（1〜5）/ CPU 追加 / パーティルール / 履歴表示 ON-OFF
- レート変動なし、戦績は「プライベート」として別集計

## 4. マッチメイキング

### ランク
```
検索範囲 = ±50（表示前の内部 rating）
5 秒ごとに +25 拡大、最大 ±400
60 秒経過で範囲制限なし
```
- 同じ相手との連戦防止：直近 3 試合の相手とは 10 分間マッチしない（人口が少ない時間帯は緩和）
- リージョン：初期は **東京 1 拠点**。ターン制かつ入力ウィンドウ方式なので ping 200ms 程度まで公平性に大きな影響なし

### カジュアル
- 内部レートで 4 人組を作るが、待ち時間優先（範囲拡大が速い）

### 実装
- Redis の Sorted Set（score = rating）で待ち行列。1 秒ごとにマッチャーが走査してペア作成
- マッチ成立 → 両者に「マッチ成立」通知 → 10 秒以内に承認（ランクのみ）→ ゲームルーム割り当て

## 5. 戦績・統計（プロフィール）

- 総試合 / 勝率 / 現在・最高ランク
- **よく出す指の数**（0/1/2 の割合）と **よく当てる数字**：自分の癖を知る＝上達要素
- 直近 20 試合の履歴（相手、結果、レート変動）
